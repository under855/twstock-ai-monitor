# 台股 AI 監控台 v0.9.4 Web

手機優先的靜態網站與 PWA。

正式網址：https://under855.github.io/twstock-ai-monitor/

## v0.9.4 重點

- 盤中行情與走勢維持 15 秒更新架構。
- 評分依趨勢、短期動能、估值、殖利率計算，缺少資料不再用固定 50 分補值。
- 評分資料覆蓋率不足 45% 時直接顯示「資料不足」，避免單一訊號產生假精準總分。
- 專業判讀會列出目前分數的主要依據與資料覆蓋率。
- 移除容易被誤解為預測的「下一交易日推動值」；評分只代表目前可取得資料下的相對強弱，不代表明日上漲機率。
- PWA 快取已升級至 v0.9.4，讓手機版能取得本次更新。

## 本機預覽

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

從 http://127.0.0.1:8000 開啟；正式 PWA 使用 HTTPS。

## GitHub Pages

使用 main 分支的根目錄（/）發布，`.nojekyll` 停用 Jekyll。更新檔案並推送至 main 後，GitHub Pages 自動部署。

`manifest.webmanifest`、`sw.js` 及圖示使用相對路徑，支援專案子路徑。
行情及新聞依賴外部公開來源；其可用性與跨來源限制獨立於網站部署。
