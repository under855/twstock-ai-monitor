# 台股 AI 監控台 v0.9.7.3

正式網址：https://under855.github.io/twstock-ai-monitor/

## 更新原則（2026-11-12）

- 台股盤中（TWSE MIS）、臺銀匯率、顯示中的美股驗證卡及個股明細新聞／配息，採每 4 秒觸發檢查；非盤中每日快照也以 4 秒觸發檢查（依來源條件）。
- 每 4 秒是檢查頻率，不保證交易所、銀行、新聞或股利來源每 4 秒發布新值。連線未結束時不重複發送同來源請求。
- 保留資料原始時間及來源，不將 HTTP 擷取時間當作報價時間。資料沒變時不重建已顯示的內容，避免閃爍。
- 來源失敗顯示「更新失敗」，後續排程自動重試；連續三次失敗觸發無整頁重載的資料復原（soft refresh），避免無限重新整理及畫面閃爍。只在 APP 內顯示，不寄錯誤通知。
- 若舊報價保留在畫面，必須同時標示為非即時／更新失敗，不可用舊價冒充即時行情。
- 證交所官方盤後資料、新聞及銀行牌告具有自身更新時間；資料驗證可能失敗，不能聲稱每四秒一定得到新資料。

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

開啟 http://127.0.0.1:8000/。
