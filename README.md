# 台股 AI 監控台 v0.9.7.4

正式網址：https://under855.github.io/twstock-ai-monitor/

## 資料更新規則

| 資料 | 檢查週期 | 注意 |
| --- | --- | --- |
| 台股盤中 TWSE MIS | 4 秒 | 僅交易時段，依交易所來源時間判定有效性 |
| 台股官方收盤快照 | 60 秒 | 不把交易日未變視為失敗 |
| 上市與上櫃盤後名冊 | 10 分鐘 | 主要用於收盤後，來源未更新不算錯誤 |
| 臺灣銀行現金／即期匯率 | 60 秒 | 顯示官方原始牌告時間；牌告不變不算更新失敗 |
| 美股 Nasdaq 代理來源 | 60 秒 | 依來源實際延遲及可用性，不承諾 4 秒新價 |
| 已開啟個股的新聞 | 5 分鐘 | 僅開啟個股明細時查詢，新聞未增加不算錯誤 |
| 已開啟個股的配息 | 6 小時 | 不需要每 4 秒下載一次日常公告 |
| 畫面狀態檢查 | 4 秒 | 不代表每 4 秒對所有來源發網路請求 |

資料有變才更新畫面，盡量避免閃爍。連線或格式驗證失敗才計算錯誤，來源未發布新資料不算錯誤；連續三次失敗觸發不重新載入整頁的資料重試。APP 本身不寄發錯誤通知。每個來源仍可能有交易日／節假日／跨網域或上游快取限制。

## 本機檢查

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```
