# 台股 AI 監控系統 v0.9.8.17

正式網站：https://under855.github.io/twstock-ai-monitor/

## 核心原則

- 正確性優先。每筆台股資料應依交易所公布的日期、時間與來源判斷；未有新成交不代表價格錯誤。
- 禁止以固定 90 秒等門檻認定有效最後成交價無效。
- 台股盤中由證交所 TWSE MIS 提供；主、次通道使用相同上游、不同轉接路徑，不能宣稱為兩個獨立行情供應商。
- 上市／上櫃日資料分別來自證交所 TWSE 及櫃買中心 TPEx 官方來源。股利與 AI 評分用的官方歷史日資料保留。
- 不使用 Yahoo 奇摩股價作為系統行情來源。外幣、新聞及境外資料是獨立功能，不能冒充台股官方報價。

## 排程與備援

| 功能 | 已核准規則 |
| --- | --- |
| MIS 第一通道 | 交易時段每 6 秒嘗試接收 |
| MIS 第二通道 | 相同 6 秒週期，初次比第一條晚 4 秒 |
| GitHub 官方 MIS 快照 | 保留原有擷取排程，前端定期讀取；只顯示可驗證日期的當日最後成交，不冒充即時報價 |
| 來源失敗 | 保留當日最後一筆已驗證價格，標示「非最新資料」，不把來源失聯當成價格本身錯誤 |
| 隔日 | 清除前一日的盤中價格與分時快取，保留官方歷史資料、追蹤清單和模擬交易 |
| 官方最近收盤價 | 不使用固定七個日曆日限制；來源與交易日期都須核對 |
| 開盤前接收查核 | 臺灣交易日上午 08:40／08:45 盤前試撮檢查；試撮不等於正式成交 |
| 網頁報價驗收 | 臺灣交易日上午 09:35 執行瀏覽器驗收，仍受 GitHub Actions 排程延誤限制 |

常態證交所主行情輪詢受交易時段與休市日曆限制。匯率、配息、新聞各自依原定頻率執行。瀏覽器背景頁面與網路故障可能延後請求；請求成功也不代表交易所剛好有新成交。

## 現行維護邊界

目前正式版主要程式：`index.html`、`live-v091.js`、`extras-v090.js`、`dividend-enhance.js`、`shared-latest-v0984.js` 等由首頁與 PWA 實際引用的模組。

重要工作流程：`update-latest.yml`、`capture-intraday-official.yml`、`update-dividends.yml`、`build-news-cache-v094r5.yml`、`midnight-source-health.yml`（名稱保留但已改為盤前檢查）、`system-data-integrity.yml`、`probe-live-browser.yml`。

舊版自動修補腳本、歷次部署文字標記、已過時的 v0.7～v0.9.4 專屬驗收工作流程已從正式分支移除；修改紀錄仍可從 Git 歷史查閱。不要再以舊版本工作流程重寫正式程式。

使用者未核准的新規則或資料時間限制，不得自行加入。故障排查與修復必須區分「來源回應失敗」、「資料最後成交時間」和「可否進行即時評分」，並進行部署前及部署後驗收。

## 本機執行

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

PWA 必須透過 HTTPS 正式部署，不能將語法測試或 CI 模擬行情通過解讀為使用者裝置已驗證盤中即時更新正常。
